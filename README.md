# 🧮 Simple Calculator

A basic and user-friendly calculator project that performs standard arithmetic operations like addition, subtraction, multiplication, and division.

---

## 🚀 Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* Modulo (%)
*  Power (^)
* Square Root (√)
*  Percentage
*  Absolute Value
*  Sine (trigonometric)
*  Cosine (trigonometric)
*  Tangent (trigonometric)
* 🧼 Clear / Reset functionality
* 💻 Simple and clean UI

---

## 🛠️ Technologies Used

* HTML
* CSS
* CPP

---

calculator/

## ▶️ How to Run

1. Clone the repository:

   ```
   git clone https://github.com/Shivamjoshi104/Calculator.git
   ```

2. Open the project folder:

   ```
   cd main
   ```

3. Run the project:

   * Open `frontend.html` in your browser if you want to run calculator on browser
